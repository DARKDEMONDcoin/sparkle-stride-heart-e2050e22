# Public site components
- Public employee pages use team.ts, employee-guides.ts and shared skills for grounded content.
- Compact navigation uses a focus-managed modal drawer with independent scrolling to keep menus bounded.
- Homepage device media uses per-employee desktop/mobile CDN screenshot pairs captured from the current chat UI with synthetic public data. Never publish private account content or let legacy videos override screenshots; previews must be accurate, privacy-safe, and before-send.
